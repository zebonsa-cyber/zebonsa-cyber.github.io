    What this report can't tell you

    • Crime. There is no reliable free national crime data at the address level. Check the local police department's crime map.
    • Exact internet providers and speeds. The FCC's address-level map needs an API key, so this report uses Census survey data on how many households subscribe. Look up the address on the FCC National Broadband Map.
    • School quality. Listed schools are the nearest public schools, not necessarily the ones assigned to this address. Confirm attendance zones with the district.
    • The building itself. Radon, lead paint, mold, foundation and roof condition need an inspection. EPA radon zones by state.
    • Official flood determinations. Lenders use official FIRM panels. Check the FEMA Flood Map Service Center.

    This is a screening tool built from public datasets with different dates and resolutions. It is not an inspection, an appraisal, or legal or insurance advice. Neighborhood figures describe the Census tract, an area of roughly 1,200 to 8,000 people, not the specific address.
